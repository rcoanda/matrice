# Projet 2 : Matrice - Phase « Do-As-I-Say » (Management directif)

## 1. Titre / Thème général
Deuxième projet de la suite dédiée à l'expérimentation du codage par IA (*AI-assisted development*), visant à concevoir un site web artistique (React, Three.js, WebGL / Vite, Node.js) en appliquant les leçons tirées du projet *Sandbox*.

## 2. L'approche 
* **Utilisation initiale du « Do-Like » :** La méthodologie de reproduction de références a été utilisée uniquement au tout début du projet pour obtenir rapidement une base de départ.
* **Pilotage direct (mode « management d'un employé ») :** Par la suite, l'IA a été pilotée pas à pas avec des instructions extrêmement précises. Les consignes ont dicté explicitement quoi faire, quoi modifier et comment organiser l'architecture.

## 3. Techniques & Génération
* **Audit itératif du code :** Analyse systématique du code généré après chaque itération pour ajuster et affiner les instructions de la requête suivante en tenant compte de l'état actuel de la base de code.
* **Architecture interne et maintenabilité :** Utilisation de prompts axés exclusivement sur la structure interne du projet (et non plus seulement sur le rendu visuel externe), afin de garantir un code lisible, modulaire et facilement extensible pour la réalisation de projets complexes.
  
## 4. Conclusions
* **Points forts / Résultats :** Obtention d'un code hyper structuré, d'un site web et d'un projet entièrement configurables et facilement paramétrables. Le projet est extrêmement maintenable : il est devenu simple d'ajouter un composant ou de formuler de nouvelles demandes complexes à l'IA sans casser l'architecture globale.
* **Points faibles / Limites :** Avec ce style de pilotage ultra-directif, la capacité d'innovation, d'imagination et d'originalité de l'IA n'a pas été exploitée. De plus, cela demande un investissement en temps constant pour le suivi de ce qui est réalisé.

## 5. La suite
* **Évolution de la démarche :** La réalisation globale se révélant extrêmement rapide, concevoir un projet unique hautement paramétrable perd de son sens. 
* **Nouveaux objectifs :** Il est préférable de multiplier les projets différents, sur des thèmes variés, dotés de structures complètement séparées et gérés individuellement. Cette approche permettra de donner l'occasion à l'IA d'être pleinement originale et de proposer des solutions créatives que l'utilisateur ou le manager ne pouvait pas concevoir ou deviner dès le départ.
